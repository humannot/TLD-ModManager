# TLD Mod Manager

Плагин MelonLoader для **The Long Dark**: автообновление модов и менеджер модов прямо в игре. Данные берутся с [tldmods.net](https://tldmods.net/).

## Возможности
- **Автообновление при запуске.** Плагин стартует раньше модов, сверяет версии установленных модов с tldmods.net и заменяет устаревшие файлы до того, как игра их загрузит, поэтому перезапуск не нужен.
- **Менеджер в игре** (клавиша **F8** или кнопка «МОДЫ» в главном меню):
  - вкладки «Установленные / Доступные / Обновления», поиск по названию, автору и категории;
  - установка в один клик вместе со всеми зависимостями;
  - список зависимостей с отметками ✓/✗ и кнопка «Докачать недостающие»;
  - обновление одного мода или всех сразу, удаление;
  - кнопки «Открыть папку модов» и «Перезапустить игру».
- Если файл мода занят запущенной игрой, замена откладывается до следующего запуска (`UserData/ModManager/pending`).

## Установка
1. Нужен MelonLoader 0.7.x.
2. Положите `ModManager.dll` в папку `TheLongDark/Plugins/` (именно **Plugins**, не Mods).

## Настройки
При первом запуске плагин спрашивает, обновлять ли моды при заходе в игру. Если ответить «Да», обновление начнёт работать со следующего запуска. Потом выбор переключается кнопкой «ОБНОВЛЯТЬ ПРИ ЗАПУСКЕ: ДА/НЕТ» в менеджере (F8).

То же самое хранится в `UserData/MelonPreferences.cfg`, секция `[ModManager]`: `AutoUpdate` (по умолчанию `false`) и `AskedAutoUpdate`.

## Ограничения
- Сам ставит `.dll`, `.modcomponent` и `.zip`. Для модов, которые распространяются в `.7z`, `.rar` или с установщиком, показывается кнопка «Страница мода».
- Установленный мод узнаётся по `MelonInfo` внутри DLL или по имени файла. Если версия мода неизвестна (например, `.modcomponent`, скопированный вручную), автообновление его не трогает, а в менеджере предлагается обновление.

## Сборка
```bash
dotnet build -c Release -p:Deploy=true
```
Путь к игре задаётся в `Directory.Build.props` (`TLDDir`) или через `-p:TLDDir=...`.
